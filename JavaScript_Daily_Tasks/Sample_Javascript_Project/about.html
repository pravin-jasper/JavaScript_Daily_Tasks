About Careerly

A simpler way to find work that fits.

Careerly is a front-end job portal demo built to make job discovery feel clear, useful, and human. Search roles, filter results, save favourites, and explore job details in one place.

🔎

Discover

Search by title and refine results by location, job type, and sorting.

🔖

Save

Bookmark opportunities and revisit them later using browser storage.

🛠️

Built to learn

HTML, Tailwind CSS, modern JavaScript, API integration, validation, and routing via pages and URL parameters.
