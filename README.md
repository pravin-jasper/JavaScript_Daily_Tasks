# JavaScript Daily Tasks 🚀

A hands-on JavaScript learning repository covering core language concepts, arrays and strings, DOM manipulation, events, form validation, browser storage, CRUD operations, and API integration. The repository is organized into day-wise folders so you can study concepts, run examples, and build projects step by step.

## 📚 Topics Covered

### 1. JavaScript Fundamentals
- Variables and data types
- Operators and expressions
- Conditional statements: `if`, `else if`, `else`, and `switch`
- Loops: `for`, `while`, `do...while`, and `for...of`
- Functions, parameters, return values, and arrow functions
- Objects and object properties

### 2. Arrays and Strings
- Creating, accessing, and updating arrays
- Common array methods: `push()`, `pop()`, `shift()`, `unshift()`, `slice()`, `splice()`, `includes()`, `find()`, and `some()`
- Iteration and transformation: `forEach()`, `map()`, `filter()`, and `reduce()`
- Working with arrays of objects
- String properties and methods such as `length`, `toUpperCase()`, `toLowerCase()`, `trim()`, `includes()`, `indexOf()`, `slice()`, `replace()`, and `split()`
- Searching, filtering, and sorting data

### 3. DOM (Document Object Model)
- Selecting HTML elements with `getElementById()`, `querySelector()`, and `querySelectorAll()`
- Reading and changing text and HTML content
- Updating styles, classes, and attributes
- Creating, appending, and removing elements
- DOM functions and reusable event-handler functions
- DOM events such as `click`, `input`, `change`, `submit`, and `DOMContentLoaded`
- Event listeners and event objects

### 4. Forms and Validation
- Reading form input values
- Checking required fields
- Validating email and other input formats
- Showing useful error and success messages
- Preventing invalid form submissions
- Resetting forms after successful submission

### 5. Data Handling and Browser Storage
- Working with objects and arrays of objects
- Searching and filtering records
- Using `map()` to transform data for display
- Saving data with `localStorage.setItem()`
- Reading data with `localStorage.getItem()`
- Converting data with `JSON.stringify()` and `JSON.parse()`
- Updating and deleting stored records

### 6. CRUD Applications
Practice the four basic data operations:
- **Create** — add a new record
- **Read** — display saved records
- **Update** — edit an existing record
- **Delete** — remove a record

A CRUD project can combine forms, DOM rendering, validation, arrays of objects, search/filter controls, and `localStorage`.

### 7. Fetch API and Asynchronous JavaScript
- Sending requests with `fetch()`
- Reading JSON responses with `response.json()`
- Handling HTTP errors with `response.ok`
- Using `async`/`await` and `try...catch`
- Displaying API data in the DOM
- Handling loading and error states

## ▶️ How to Run the Tasks

1. Clone or download the repository.

   ```bash
   git clone https://github.com/pravin-jasper/JavaScript_Daily_Tasks.git
   ```

2. Open the project folder in your code editor.
3. Open the relevant day or task folder.
4. Open its `index.html` file in a browser. For a more convenient development workflow, use a local server such as the **Live Server** extension in VS Code.
5. Open the browser developer tools and check the **Console** for JavaScript output or errors.

Some tasks may contain only JavaScript files or may use a different entry-file name. In those cases, follow the files available inside that task folder.

## 🧭 Using the Main Dashboard

If the repository's main `index.html` dashboard is present, open it to browse the available day folders and tasks. If a folder link does not open, check that the folder contains the target `index.html` file and that the relative path in the dashboard matches the actual folder name.

## 💡 Suggested Practice Projects

Use the concepts above in small projects, increasing the difficulty gradually:

1. **Condition and Loop Exercises** — grade calculator, number checker, multiplication table, and pattern printing.
2. **Array and String Toolkit** — search names, remove duplicates, count characters, and filter products.
3. **Form Validation Page** — validate user input and display clear inline messages.
4. **Searchable Data List** — render an array of objects and search/filter the displayed records.
5. **To-Do List** — add, complete, edit, and delete tasks; save them in `localStorage`.
6. **Student or Contact Manager** — build a CRUD interface with form validation and persistent browser storage.
7. **API Data Explorer** — fetch data from a public API and show loading, success, and error states.

## ✅ Recommended Learning Order

1. Variables, operators, conditions, and loops
2. Functions and objects
3. Arrays, array methods, and string methods
4. Arrays of objects, search, filter, and map
5. DOM selection and manipulation
6. DOM events and form validation
7. `localStorage` and JSON
8. CRUD applications
9. Fetch API, promises, and `async`/`await`
10. Combine the concepts in a complete project
